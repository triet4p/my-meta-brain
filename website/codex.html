Kết nối Codex CLI

Windows x64 · gói MCP tự chứa Meta Brain 1.1.0. Sprint 9 chấp nhận quan sát Codex CLI 0.164.0; đây là phiên bản đã quan sát, không phải dải tương thích được cam kết.

Điều kiện trước

  • Giải nén toàn bộ MCP ZIP vào đường dẫn ổn định; giữ nguyên mcp/ và service/. Không cần CLI/Owner UI, SDK, repo hoặc .NET runtime.
  • Chọn đúng data root hiện dùng bởi owner; instance mới sẽ khởi động khóa. Owner phải tự start/provision/unlock qua CLI hoặc Owner UI. Codex/MCP không có quyền unlock, publish catalog, approve/reject, cấp quyền hoặc revoke.
  • Owner cần công bố catalog và phê duyệt request riêng trước khi agent đọc nội dung. Việc kết nối không cấp quyền.

Cấu hình tạm theo process

Thay <isolated-workspace> bằng workspace dự án và <owner> bằng tài khoản Windows; giữ nguyên dấu ngoặc kép và escape kép trong giá trị TOML. Ví dụ cung cấp đúng một instance selector --data-root:

codex -C "<isolated-workspace>" -c 'mcp_servers.metabrain.command="C:\\Users\\<owner>\\AppData\\Local\\MetaBrain\\MCP\\1.1.0\\mcp\\MetaBrain.Mcp.exe"' -c 'mcp_servers.metabrain.args=["--data-root","C:\\Users\\<owner>\\AppData\\Local\\MetaBrain\\Data"]'

Đây là process-only -c override, không tự lưu profile và không gửi prompt. Nếu dùng settings file hiện hữu, thay cặp args bằng ["--config","C:\\...\\service-settings.json"], không thêm cả hai selector. Không dùng mcp add hoặc thay user profile. Đường dẫn absolute tới mcp/MetaBrain.Mcp.exe; gói tự chọn service executable kế bên. Đối số là đường dẫn thường, chuỗi Codex cần escape backslash như ví dụ.

Kết quả và xử lý

Codex khởi chạy MCP stdio; MCP nối cùng shared host và giữ stdout cho JSON-RPC. Khởi động instance sạch tạo settings không nhạy cảm nhưng vault locked. Owner unlock/approve riêng; agent thấy catalog metadata, request ID/status, và chỉ dữ liệu trong scope sau owner approval + one-time handoff redeem.

Launch failure: xác minh ZIP đã giải nén đầy đủ, executable path absolute tồn tại, đúng một selector và root đúng. Vault locked: owner unlock qua frontend; agent không thể sửa. Request pending/denied: owner review attached-console preview, thu hẹp scope hoặc reject. Thu hồi/lock/restart làm phiên mất hiệu lực. Không cấu hình key/bearer; chỉ đường dẫn handoff/session DPAPI-protected đi qua tích hợp. Đã gửi nội dung cho model/provider thì lock/revoke không thể thu hồi nội dung đó.

Không tự sửa profile toàn cục; xóa/điều chỉnh override tạm trong lệnh khi xong. Hướng dẫn owner duyệt đầy đủ: Tình huống agent truy cập. Chi tiết: Runbook §3.2.1.

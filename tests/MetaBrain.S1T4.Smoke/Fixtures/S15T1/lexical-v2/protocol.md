# S15-T1 E5 candidate evaluation protocol

**Scope:** standalone local CPU comparison only. This does not change product search, add CLI/MCP semantic behavior, or implement hybrid ranking. The pinned E5-small full-precision export remains an evaluation candidate; runtime, tokenizer, export, distribution, engine choice and quality/resource targets remain unapproved.

## Frozen inputs and reproducibility

The source-controlled `corpus.json` and `queries.json` here are byte-identical to the original frozen v2 manifests under `artifacts/sprint-15/evaluation/lexical-v2/` at A4 start. Fixed SHA-256 identities:

- `corpus.json`: `4ec9b83ef3b0483c70cdaa51be2cedd611d31430643f8e0b97aacfb8908fa806` (5,905 bytes)
- `queries.json`: `261c017433882d54aece88f5740007ce026e9320d26ad96dbceeb30cb4a5f9be` (11,614 bytes)

The corpus is synthetic-only: 12 source documents, current revision selected for both revisioned files, and 100 deterministic 1,024-byte distractors generated by the evaluator. The fixed 35 held-out workspace queries and labels remain unchanged. Their supplemental agent-scope fixtures/queries are present in the frozen manifests but are not run by this standalone model comparator; the evaluator does not claim agent authorization or scope behavior. Any frozen input hash mismatch is fatal. No held-out labels or ranking thresholds may be changed or tuned for this run.

The pinned assets are the seven exact files at revision `614241f622f53c4eeff9890bdc4f31cfecc418b3` under `runtime/s15-t1-model-staging/<revision>/model`; their manifest sizes and SHA-256/Git-blob identities are enforced in source. The six approved package files are read only from the repo-local pinned NuGet feed. Model/package bytes remain ignored runtime staging; the evaluator, protocol and frozen JSON inputs are source-controlled under `tests/`.

## Required process-local execution

From the repository root, execute in one PowerShell process. Do not use `DOTNET_SKIP_FIRST_TIME_EXPERIENCE`; it is unsupported by modern .NET and is not a safety control. No global environment changes, external package source, model download, host-store inspection/remediation, cloud call or private input is permitted.

```powershell
$repo = (Get-Location).Path
$revision = '614241f622f53c4eeff9890bdc4f31cfecc418b3'
$env:DOTNET_GENERATE_ASPNET_CERTIFICATE = 'false'
$env:DOTNET_NOLOGO = '1'
$env:DOTNET_CLI_TELEMETRY_OPTOUT = '1'
$env:DOTNET_CLI_WORKLOAD_UPDATE_NOTIFY_DISABLE = 'true'
$env:DOTNET_CLI_HOME = Join-Path $repo 'runtime\s15-t1-evaluation\dotnet-cli-home'
$env:NUGET_PACKAGES = Join-Path $repo 'runtime\s15-t1-evaluation\nuget-packages'
$project = Join-Path $repo 'tests\MetaBrain.S1T4.Smoke\MetaBrain.S1T4.Smoke.csproj'
$config = Join-Path $repo 'runtime\s15-t1-evaluation\NuGet.Config'
$packages = Join-Path $repo 'runtime\s15-t1-evaluation\nuget-packages'
$model = Join-Path $repo ("runtime\s15-t1-model-staging\$revision\model")
dotnet restore $project --configfile $config --packages $packages --no-cache
if ($LASTEXITCODE -ne 0) { throw "Local-only restore failed: $LASTEXITCODE" }
dotnet build $project --configuration Debug --no-restore
if ($LASTEXITCODE -ne 0) { throw "Focused build failed: $LASTEXITCODE" }
dotnet run --no-build --no-restore --project $project -- s15-t1-e5 $repo $model
if ($LASTEXITCODE -ne 0) { throw "Candidate evaluation failed: $LASTEXITCODE" }
```

`runtime/s15-t1-evaluation/NuGet.Config` clears all other package sources and names only the pinned local feed. The six exact package versions are approved for this isolated synthetic evaluation; `System.Memory` remains available as a transitive dependency and is not directly referenced because restore identified its direct reference as unnecessary. The evaluator writes a measurement record to ignored `artifacts/sprint-15/evaluation/lexical-v2/e5-candidate-results.json`.

## Candidate behavior and observations to record

- Admit all seven model/tokenizer/config assets by exact size/hash before loading either tokenizer or ONNX model.
- Compare every public .NET SentencePiece vocabulary ID against all 250,002 tokenizer.json entries; inspect tokenizer.json's precompiled normalizer hash/structure, metaspace, special-token IDs and single-sequence BOS/content/EOS template; check the loaded tokenizer's public whitespace flags and `query: ` / `passage: ` BOS/EOS probes. The precompiled map is not compared to the internal SentencePiece model map, and there is no independent Hugging Face token-ID oracle or full token-for-token parity test.
- Validate the pinned mean-pooling config, ONNX input names/types/ranks and token-hidden output shape. Embed every current source as `passage: <complete file>` and query as `query: <frozen text>`, right-truncate to 512 tokens while preserving EOS, create the attention mask, mean-pool only mask-1 token outputs, then L2-normalize.
- Rank full source files inside the frozen `inside` folder by cosine score, deterministic path tie-break. Check expected current path/revision and anchor presence in the synthetic source. This is not passage segmentation, exact byte-span/citation validation, workspace authorization, agent-scope evaluation or product CLI/MCP integration.
- Report per-query top five paths/revisions/scores, expected-source recall@1/@5 and family counts; keep unlabeled/hard-negative similarity scores diagnostic because no score threshold is approved.
- Record asset/pooling/tokenizer/ONNX compatibility observations including model config `pad_token_id=0` vs tokenizer `<pad>` ID 1 and model config vocabulary size vs tokenizer/runtime vocabulary count. Do not suppress, silently substitute, or claim upstream guarantees from a successful inference call.
- Measure tokenizer/session cold load, first passage, separate tokenizer/inference/pooling timings, 10 warmups and 100 warm query searches, process CPU and private/working memory at observed boundaries, plus exact raw staged asset/package bytes. These are one local run, not product latency, isolated native peak memory, installed footprint, corpus-scale or deployment measurements.
- Preserve the historical lexical-v2 CLI/service/MCP measurements as a separate comparator only; do not rerun or describe them as semantic candidate evidence. No numerical proposal in the owner packet is an approved pass/fail gate.

Kết nối Oh My Pi (OMP)

Windows x64 · gói MCP tự chứa Meta Brain 1.0.0. Sprint 9 đã quan sát OMP 18.12.6; đây là phiên bản evidence, không xác lập dải tương thích.

Điều kiện trước

  • Giải nén toàn bộ ZIP vào vị trí ổn định; giữ nguyên cấu trúc mcp/ và service/. MCP không cần cài frontend owner, SDK hoặc runtime .NET.
  • Tạo cấu hình chỉ trong workspace cô lập bạn chọn, tại .omp/mcp.json; tránh repo sản phẩm, thư mục profile người dùng và cấu hình toàn cục.
  • Data root phải là instance owner đã chọn. Host khởi động locked; owner phải tự start/provision/unlock, công bố catalog, xem và duyệt request. MCP/OMP không có quyền owner, key, publish/approve/revoke.

Project-local JSON

Thay <owner> và đường dẫn dữ liệu bằng giá trị của bạn. Trong JSON, Windows backslash phải escape thành \\. Chỉ dùng một cặp selector:

{
  "mcpServers": {
    "metabrain": {
      "type": "stdio",
      "command": "C:\\Users\\<owner>\\AppData\\Local\\MetaBrain\\MCP\\1.0.0\\mcp\\MetaBrain.Mcp.exe",
      "args": ["--data-root", "C:\\Users\\<owner>\\AppData\\Local\\MetaBrain\\Data"]
    }
  }
}

Nếu trỏ vào settings hiện hữu, đổi args thành ["--config", "C:\\...\\service-settings.json"]; không thêm đồng thời --data-root. command phải là đường dẫn tuyệt đối đến MCP executable đã giải nén, không phải service executable. Runtime được tìm cạnh đó.

Khởi chạy OMP từ chính workspace với session tắt:

omp --cwd "<isolated-workspace>" --no-session

Không dùng /mcp add, không tự sửa profile toàn cục. Snippet chỉ đăng ký process stdio; nó không tạo quyền truy cập hay gửi prompt.

Kết quả và xử lý

Client mở MCP stdio trên shared host; host sạch tạo settings nonsensitive nhưng vẫn locked. Agent chỉ xem metadata catalog, gửi request purpose/context và hỏi trạng thái. Owner xem preview gắn console, chọn operations/resources phù hợp, đặt expiry UTC tương lai, duyệt tường minh và chuyển file handoff DPAPI-protected; agent redeem một lần vào session file. Agent không thể provision/unlock/approve/issue/revoke.

Không kết nối: kiểm tra JSON hợp lệ, path đầy đủ, ZIP layout, workspace đang dùng và selector duy nhất. Request pending/denied cần owner review; locked host cần owner unlock. Lock, restart, expiry hoặc revoke vô hiệu hóa quyền. Không đưa key/token vào file cấu hình, logs, prompt hay output lưu lại. Nội dung đã gửi cho provider không thể được thu hồi bởi Meta Brain.

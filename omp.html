Compatibility evidence: Sprint 17 T5 đã quan sát Codex CLI 0.164.0 và OMP 18.20.0 trên source T5 đã review; đây là evidence points lịch sử, không phải range/minimum SDK support và không phải smoke normal-client của gói 1.8.0. MCP thương lượng protocol offer 2025-11-25, 2025-06-18, 2025-03-26 hoặc 2024-11-05; offer thiếu/không biết dùng 2025-11-25.

Điều kiện trước

  • Giải nén toàn bộ ZIP vào vị trí ổn định; giữ nguyên cấu trúc mcp/ và service/. MCP không cần cài frontend owner, SDK hoặc runtime .NET. Cần Microsoft Visual C++ v14 x64 Redistributable 14.43.34808 trở lên do owner tự cài; MCP từ chối khởi động nếu thiếu hoặc quá cũ.
  • Tạo cấu hình chỉ trong workspace cô lập bạn chọn, tại .omp/mcp.json; tránh repo sản phẩm, thư mục profile người dùng và cấu hình toàn cục.
  • Data root phải là instance owner đã chọn. Host khởi động locked; owner phải tự start/provision/unlock, công bố catalog, xem và duyệt request. MCP/OMP không có quyền owner, key, publish/approve/revoke.

Project-local JSON

Thay <owner> và đường dẫn dữ liệu bằng giá trị của bạn. Trong JSON, Windows backslash phải escape thành \\. Chỉ dùng một cặp selector:

{
  "mcpServers": {
    "metabrain": {
      "type": "stdio",
      "command": "C:\\Users\\<owner>\\AppData\\Local\\MetaBrain\\MCP\\1.8.0\\mcp\\MetaBrain.Mcp.exe",
      "args": ["--data-root", "C:\\Users\\<owner>\\AppData\\Local\\MetaBrain\\Data"]
    }
  }
}

Nếu trỏ vào settings hiện hữu, đổi args thành ["--config", "C:\\...\\service-settings.json"]; không thêm đồng thời --data-root. command phải là đường dẫn tuyệt đối đến MCP executable đã giải nén, không phải service executable. Runtime được tìm cạnh đó.

Khởi chạy OMP từ chính workspace với session tắt:

omp --cwd "<isolated-workspace>" --no-session

Không dùng /mcp add, không tự sửa profile toàn cục. Snippet chỉ đăng ký process stdio; nó không tạo quyền truy cập hay gửi prompt.

Kết quả và xử lý

Client mở MCP stdio trên shared host; host sạch tạo settings nonsensitive nhưng vẫn locked. Agent chỉ xem metadata catalog, gửi request purpose/context và hỏi trạng thái. Owner xem preview gắn console, chọn operations/resources phù hợp, đặt expiry UTC tương lai, duyệt tường minh và chuyển file handoff DPAPI-protected; agent redeem một lần vào session file. Agent không thể provision/unlock/approve/issue/revoke.

Không kết nối: kiểm tra JSON hợp lệ, path đầy đủ, ZIP layout, workspace đang dùng và selector duy nhất. Request pending/denied cần owner review; locked host cần owner unlock. Lock, restart, expiry hoặc revoke vô hiệu hóa quyền. Không đưa key/token vào file cấu hình, logs, prompt hay output lưu lại. Nội dung đã gửi cho provider không thể được thu hồi bởi Meta Brain.

Sprint 17: workspace tools

metabrain_workspace_folder_request accepts only a stable folder ID and purpose; the server fixes the requested operation to workspace.file.read and returns an opaque pending receipt. Check only its state with metabrain_workspace_request_status. A folder ID is not inferred from a path, working directory or MCP root.

The owner reviews owner workspace-requests and may record review with owner workspace-request-resolve; resolving is non-authoritative. To grant file reads, the owner separately previews and explicitly approves the exact D108 snapshot with workspace-share-preview and workspace-share-approve. Contextual reads through metabrain_workspace_agent_recall require a separate D111 workspace.agent.recall preview and approval selecting cognitive, hybrid and/or relation operations with exact pins. Semantic hybrid queries still require separate local-inference consent.

Existing metabrain_workspace_context_pack (D110), metabrain_scoped_read, metabrain_source_read and metabrain_propose continue to use their own grants. Workspace recall does not imply source access, proposal authority, provider egress or owner actions. Revoke the relevant grant or lock the vault to deny further calls; content already delivered to a client cannot be recalled.
